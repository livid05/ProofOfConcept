Tyler Judkins · Capstone · October 22, 2026 · 18

How it was measured: a separate test image on the same board and USB endpoint settings streamed numbered reports; a PC program read them for 10 seconds and timed them with the device’s own microsecond clock. Result: 7,999 reports per second, 79,995 received, none dropped, 100% of gaps near the ideal 125 µs, worst gap 1,125 µs. This shows the USB path can run at 8K. It does not measure key-to-screen latency, and the real keyboard only sends a report when a key changes. The 1,000 bar is the 1K reference rate and the 8,000 bar is the nominal 8K target, not measurements.
