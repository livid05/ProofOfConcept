Debounce: fast press, filtered release

if (raw_pressed != stable_pressed &&

    ((KEY_EAGER_PRESS && raw_pressed) ||

     (now_us - raw_changed_us)

      >= KEY_DEBOUNCE_US))

{

    stable_pressed = raw_pressed;

    edge = 1;

    if (stable_pressed)

        key_press_count++;

}

What it does

  • With eager press on, the first low sample is a press.
  • Release needs 10 ms (10,000 µs) of continuous high.
  • Bounce while held cannot create a second press.
  • Setting eager press to 0 filters both edges if noise appears.

Source: key_switch.c (one-key version; key_matrix.c applies the same rules to each key)
