4 · Technical documentation · Firmware flow

Every pass of the main loop follows five steps

1

Sample

Read PB4 every 125 µs using the 1 MHz TIM2 clock.

2

Press

The first low sample counts as a press at once.

3

Release

The pin must stay high for 10 ms first.

4

Queue

Store the event in a 15-slot ring buffer.

5

Send

Send an 8-byte report when USB is free. Release is all zeros.

Safeguards: a key held during plug-in is ignored until released. A full queue resets to all-keys-up. A release is never dropped, so no key sticks.
