2 · The solution delivered

Custom hardware, bare-metal firmware, one-click tools

Hardware

  • Devboard RevK with an STM32U5A5 microcontroller
  • Numpad RevE: 4 × 4 board, 15 keys plus encoder, TMR footprints, RGB
  • Designed in KiCad, built by JLCPCB

Firmware

  • USB boot keyboard on the high-speed port
  • 125 µs switch scan, fast press, filtered release
  • Queued reports so no press or release is lost

Toolchain

  • Build and USB flash buttons in VS Code
  • Host-side logic tests of the real switch code
  • Saved known-good firmware to fall back on

Working today: one mechanical key (MX2) types “a”, repeats while held and stops on release, over USB high speed.
